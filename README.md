# ポイッと

自分の **Mac・Windows・iPhone・iPad・Android** の間で、写真・書類・メモ・URL をブラウザだけでサッと受け渡す、自分専用のWebアプリです。
Cloudflare Workers・R2・Durable Objects で動き、データは **あなた自身のCloudflareアカウントの中だけ** に置かれます。

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/yuichi4107-lab/poitto-app)

- 1ファイル最大 2GB（大きなファイルは自動で小分けにして送信）
- 24時間で自動お片付け（受信トレイの記録と R2 のファイルを自動削除）
- アプリのインストール不要（ホーム画面／デスクトップに追加可能な PWA）

## できること

- **ファイルを送る**：ドラッグ＆ドロップか、クリックで選ぶだけ。複数まとめて送れます。
- **テキストやURLを送る**：貼り付けて送信。受け取った側は「コピー」ひとつで使えます。
- **すぐに届く**：開いているほかの端末の「受信トレイ」に自動で表示されます。画像はプレビュー付き。
- **共有リンク**：受信トレイの項目からリンクとQRコードを作成。リンクを知っている人はログインなしで受け取れます（最長24時間）。
- **24時間で自動お片付け**：送信から24時間たった項目は自動で消えます（15分ごとに実行）。手動削除もできます。
- **自分だけの専用アプリ**：1つの設置＝1人の持ち主。使えるのは自分が登録した端末だけです。

## 対応端末

| 端末 | ホーム画面／デスクトップへの追加 |
|---|---|
| Mac | Safari：「ファイル」→「Dockに追加」／Chrome・Edge：アドレスバーのインストールアイコン |
| Windows | Chrome・Edge：画面上の「インストール」ボタン、またはアドレスバーのインストールアイコン |
| iPhone | Safari：共有ボタン →「ホーム画面に追加」 |
| iPad | Safari：共有ボタン →「ホーム画面に追加」 |
| Android（Pixelなど） | Chrome：︙メニュー →「ホーム画面に追加」または「アプリをインストール」 |

### iPhone・iPad の注意

iPhone・iPad では、**Safari とホーム画面のアプリでログイン情報が別々** に保存されます。ホーム画面のアイコンから開くとログイン画面が出るので、

1. ログイン済みのほかの端末で「端末を追加」を押し、6桁コードを表示する
2. ホーム画面のポイッとを開き、ログイン画面の「6桁コードで追加」にコードを入力する

（パスフレーズでログインしても構いません。）不要になった古い登録は「端末一覧」から取り消せます。

## 設置手順（自分のCloudflareに設置）

### 用意するもの

- Cloudflare アカウント（無料プランで始められます）
- **R2 の有効化**：毎月10GBまで無料ですが、有効化の際に支払い方法（クレジットカードなど）の登録が必要です。
- GitHub（または GitLab）アカウント：設置ボタンを押すと、このリポジトリのコピーがあなたのアカウントに作られます。
- 管理者パスフレーズ：自分で決める合言葉。長めで推測されにくいものにして、パスワード管理アプリなどに保管してください。

### 手順

1. **R2 を有効にする**：Cloudflare ダッシュボードの「R2」から利用を開始します（有効済みなら不要）。
2. **上の「Deploy to Cloudflare」ボタンを押す**：GitHub と Cloudflare にログインし、Worker名などを確認します。R2 バケットと Durable Objects は自動で作られます。
3. **2つのシークレットを入力する**（あとからダッシュボードの Worker →「設定」→「変数とシークレット」でも変更できます）
   - `ADMIN_SETUP_PASSPHRASE`：自分で決めた管理者パスフレーズ。これがないと初回セットアップできないので、他人に勝手に初期設定されるのを防げます。
   - `COOKIE_SIGNING_KEY`：ログイン状態を守るためのランダムな長い文字列（例：`openssl rand -hex 32` の出力。英数字64文字ほど）。覚えておく必要はありません。
4. **初回セットアップ**：`https://（Worker名）.（あなたのサブドメイン）.workers.dev` をパソコンで開くと「初回セットアップ」画面が出ます。端末名と、手順3のパスフレーズを入力して「設定して開始」を押します。セットアップは最初の1回だけです（パスフレーズを何度も間違えると、しばらく試せなくなります）。
5. **ほかの端末を追加する**：「端末を追加」で表示される QR コードを読み取るか、新しい端末のログイン画面で「6桁コードで追加」に入力します（コードは5分間・1回だけ有効）。

### コマンドで設置する場合

```bash
npm ci
npx wrangler login
npx wrangler r2 bucket create poitto-items   # R2 が有効になっている必要があります
npx wrangler secret put COOKIE_SIGNING_KEY
npx wrangler secret put ADMIN_SETUP_PASSPHRASE
npm run deploy
```

ローカルで試すときは `cp .dev.vars.example .dev.vars` で値を入れてから `npm run dev`。

## 費用の目安

自分で使う程度なら、多くの場合は無料枠に収まります（2026年11月時点の Cloudflare 公式情報）。

| サービス | 無料で使える量 | 超えた場合 |
|---|---|---|
| Workers（アプリ本体） | 1日10万リクエスト | 無料プランではその日は使えなくなります |
| R2（ファイル置き場） | 毎月10GB分の保存、書き込み100万回、読み出し1,000万回 | 保存1GBあたり月$0.015など（登録した支払い方法に請求） |
| データ転送（ダウンロード） | 無料 | — |
| Durable Objects（記録の保存） | 無料プランにも無料枠あり | 無料プランでは上限で止まります |

大きなファイルを置いたままにすると R2 の保存量が増えます。心配な方は請求通知を設定してください。詳細は [R2 の料金](https://developers.cloudflare.com/r2/pricing/) と [Workers の制限](https://developers.cloudflare.com/workers/platform/limits/) を確認してください。

## 制限・注意

- 1ファイルの上限は 2GB です（`MAX_FILE_BYTES`）。
- 項目と共有リンクの保持時間は 24 時間です（`RETENTION_HOURS`）。
- 共有リンクはリンクを知っている人なら誰でも開けます。渡す相手に注意してください。
- パスフレーズを画面から変更・再設定する機能はありません。ログイン済みの端末があれば、6桁コードで新しい端末を追加できます。
- 「1つの設置＝1人の持ち主」です。家族などが使う場合は、それぞれのCloudflareアカウントに設置してください。

## 仕組み

- `src/worker.ts`：API・認証・共有リンク・定期お片付け（cron `*/15 * * * *`）
- `src/hub.ts`：Durable Object（受信トレイ・端末・セッション・ペアリングの記録、WebSocket 通知）
- `frontend/`：PWA の画面（Workers Static Assets）
- ファイルは R2（バインディング `BUCKET`）に保存されます。
